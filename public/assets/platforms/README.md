# Platform Logos

This directory contains the official logos for various streaming and social media platforms used in the earnings feature.

## Required Logo Files

Place SVG logo files in this directory with the following names:

- `spotify.svg` - Spotify logo
- `apple-music.svg` - Apple Music logo
- `tiktok.svg` - TikTok logo
- `youtube-music.svg` - YouTube Music logo
- `youtube-content-id.svg` - YouTube Content ID logo
- `youtube-shorts.svg` - YouTube Shorts logo
- `instagram.svg` - Instagram logo
- `facebook.svg` - Facebook logo
- `amazon.svg` - Amazon Music logo

## Logo Guidelines

1. **Format**: SVG is preferred for scalability, but PNG is also supported
2. **Size**: Logos will be displayed at 16px (sm), 24px (md), and 32px (lg)
3. **Background**: Use transparent backgrounds
4. **Color**: Use official brand colors or white versions for dark backgrounds
5. **Licensing**: Ensure you have proper rights to use each platform's logo

## Fallback Behavior

If a logo file is not found, the component will automatically fall back to a colored circle with the platform's initials.

## Where to Get Logos

Most platforms provide official logo assets through their brand resources:

- **Spotify**: https://developer.spotify.com/documentation/design
- **Apple Music**: https://developer.apple.com/apple-music/marketing-guidelines/
- **TikTok**: https://www.tiktok.com/about/brand-guidelines
- **YouTube**: https://www.youtube.com/about/brand-resources/
- **Instagram**: https://about.instagram.com/brand/resources
- **Facebook**: https://about.meta.com/brand/resources/
- **Amazon Music**: Contact Amazon Music brand team

Always follow each platform's brand guidelines when using their logos.
